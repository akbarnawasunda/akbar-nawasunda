# BRAND_IDENTITY

## Core Positioning
Akbar Nawasunda = produser independen Bandung Barat yang menjembatani akar Sunda modern dengan kultur breakbeat / Indo bass. Bukan DJ template, bukan startup.

DJ Akbar Remix adalah chapter awal (2020-2023), kini berevolusi menjadi Akbar Nawasunda — lebih mature, producer-oriented.

## Personality
- Premium but grounded (Bandung Barat, bukan LA)
- Cinematic, atmospheric, but functional
- Rhythm-driven, not effect-driven
- Authentic, not over-glow AI

## Visual Pillars
1. **Near-black editorial** — seperti akbarnawasunda.my.id sekarang: dark, tight typography
2. **Luminous signal** — aksen biru #0087FF sebagai sinyal, bukan dekorasi
3. **Sculptural depth** — layering, material, bukan flat neon gradient
4. **Cultural subtle** — hint Sunda modern tanpa batik klise

## Logo Usage
- AN tajam: jangan redraw, jangan bulatkan, jangan kasih glow berlebihan. Clear space = 0.5x tinggi logo.
- Versi hitam-biru untuk light bg, putih untuk dark.
- RMX logo metal hanya untuk section history / alias, bukan primary.

## What to Avoid
- Random floating spheres, particle spam, glassmorphism everywhere, glitch spam, unreadable fonts.
