# CONTENT_GUIDELINES

## Verified vs Placeholder
- NEVER invent release titles. Use only verified list in FACTS_AND_VERIFICATION.
- If missing, write [NEEDS OWNER: ...]

## Asset Usage
- AN mark: primary nav, favicon, loading. Use transparent PNG akbar-an-mark-transparent.png. Minimum size 24px, clear space 0.5x.
- Full lockup: use only in footer, EPK, history section. Not in nav. Use akbar-nawasunda-full-transparent.png white version on dark, black version on light (invert via CSS filter if needed).
- Portrait: hero only, not repeated. WebP 1200px, lazy except LCP. No crop face.
- Background texture: subtle paint splatter from original logo is NOT to be used as overlay everywhere — only as 2% opacity on hero maybe.

## Copy Length
- Hero sub: max 12 words
- Release description: max 200 chars preview, full markdown detail page.
