# STUDIO_PRD

## Goal
Owner bisa kelola konten tanpa dev, <3 menit per rilis.

## Features MUST v1
- Login / logout, session
- Dashboard: counts published/draft, quick actions
- Releases: list, create, edit, delete, draft/publish toggle, reorder featured
- Visuals: upload, tag category
- Links: edit social links
- Media library: browse, delete, preview
- Preview before publish (open public page with ?preview token)
- Unsaved change guard

## SHOULD
- Drag order releases
- Export JSON backup
- Audit log publish

## OUT OF SCOPE v1
- Multi-user roles (single admin v1)
- Rich text heavy editor (markdown simple)
