# PROJECT_CHARTER

## Vision
Membangun rumah digital definitif untuk Akbar Nawasunda — produser/remixer/DJ asal Bandung Barat (since 2020) — yang terasa premium, immersive, music-first, dan punya karakter yang bisa dikenali tanpa nama.

## Problem with existing
- Template DJ generik, tidak mencerminkan evolusi DJ Akbar Remix → Akbar Nawasunda
- Tidak ada arsip visual & rilis yang terstruktur
- Tidak ada sistem owner-controlled untuk update konten

## Goals
1. Establish primary identity Akbar Nawasunda dengan menghormati alias historis.
2. Listening path <5 detik: visitor paham siapa & di mana dengar musik.
3. 3D signature "Liquid Signal" — sculptural, bukan dekorasi random.
4. Owner bisa kelola rilis, visual, link tanpa developer.
5. Performa real-world Android low-end tetap usable.

## Non-Goals (OUT OF SCOPE v1)
- Ticketing system
- Merch e-commerce full
- Multi-bahasa di luar ID/EN (EN = optional phase 2)
- Forum / community

## Success Metrics
- LCP <2.5s, CLS <0.1, INP <200ms
- Homepage CTA listen click >60% first session
- 3D fallback success rate 100% (no blank page)
- Owner bisa publish rilis baru <3 menit via Studio
