# GLOSSARY
- **Liquid Signal:** Konsep 3D signature: material cair metalik yang mengalir seperti sinyal bass, representasi evolusi DJ Akbar Remix → Akbar Nawasunda.
- **AN:** Monogram logo tajam hitam-biru.
- **RMX:** Suffix untuk alias remix era.
- **Potret Neon:** Sesi foto studio gelap dengan rim light biru-ungu, jadi visual utama.
- **Studio:** Custom CMS owner-controlled di /studio.
- **Release:** Single/track yang publish di platform streaming.
- **EPK:** Electronic Press Kit.
