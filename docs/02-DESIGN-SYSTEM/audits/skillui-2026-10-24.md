## What it got wrong — do not act on these

- **"Fonts: 1", "sans-serif throughout".** False. The site ships Instrument Serif (display, roman +
  italic), Instrument Sans (body) and JetBrains Mono (labels), self-hosted through `next/font/local`.
  skillui only follows `font-family` declarations it can see in CSS, and those resolve through
  `next/font` variables at runtime.
- **"Motion: expressive — spring physics, layout animations."** There is no spring library in this
  repository and no layout animation. The motion is one rAF loop writing transforms.
- **"Spacing scale: 2, 4, 6, 8, 10, 12, 18, 20 px."** That is a frequency histogram of the values it
  saw, not the scale. The scale is in `tokens.css` (`--space-1` … `--space-32`).
- **`#1a93ff` as the accent.** It is `--color-signal-blue-hover`; the accent is `#0087ff`.

Because of the first two errors this report is **not** wired into the build, and its output is not
committed as a "design system" that a future agent should code against. The durable part of the

(`scripts/token-audit.mjs`), which checks both directions: hex values outside `tokens.css`, and

- Use **sans-serif** for all text — do not mix font families

- Headings use bold (600-700), body uses regular (400)

- Use color and opacity for secondary hierarchy, not additional font sizes

## 8. Do's and Don'ts

### Do's

- Use `#1a93ff` for interactive elements (buttons, links, focus rings)
- Use `#0a0a0e` as the primary page background
- Use **sans-serif** for all UI text
- Follow the **4px** spacing grid for all margins, padding, and gaps
- Use the defined shadow tokens for elevation — see Section 6
- Use border-radius from the scale: 2px, inherit
- Reuse existing components from Section 4 before creating new ones

### Don'ts

- Don't introduce colors outside this palette — extend the design tokens first
- Don't mix font families — use sans-serif consistently
- Don't use arbitrary spacing values — stick to multiples of 4px
- Don't create custom box-shadow values outside the system tokens
- Don't use arbitrary border-radius values — pick from the defined scale
- Don't duplicate component patterns — check Section 4 first
- Don't use backdrop-blur or blur effects

### Anti-Patterns (detected from codebase)

- No blur or backdrop-blur effects
- No zebra striping on tables/lists
