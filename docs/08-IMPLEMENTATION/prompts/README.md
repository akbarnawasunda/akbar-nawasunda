# Prompt archive

The bootstrap and phase prompts the owner wrote for the build, kept as history. They used to sit at
the repository root, where eleven of them competed with the two files an agent actually has to read
(`AGENTS.md`, `CONTEXT.md`) and with `README.md`, which is the front door for a human.

Nothing here is a live instruction. `AGENTS.md` wins over everything in this folder — several of
these prompts describe a stack the site no longer runs (Instrument Serif / Instrument Sans /
JetBrains Mono, five type roles, a particle "liquid signal", Tailwind-era utility classes), and
`AGENTS.md` was rewritten precisely to cancel those.

| File | What it was for |
| --- | --- |
| `PROMPT_AWAL_AGENT.md` | The first bootstrap prompt: build the blueprint package. |
| `PROMPT_FINAL_V9_ANTI_AI_REAL_ASSETS.md` | Round where generated "AI-looking" effects and placeholder art were banned. |
| `PROMPT_FINAL_V10_SINGLE_SOURCE.md` | One source of truth for content, no duplicated copy. |
| `PROMPT_FINAL_V11_CLEAN_REPO.md` | Repository hygiene pass. |
| `PROMPT_HAPUS_SIGNAL_ANTI_AI.md` | Order to delete the signal-field effects. |
| `PROMPT_PHASE7_3D_MUSIC_NOTES_AND_ARTWORK.md` | The 3D / music-notation phase. |
| `PROMPT_REDESIGN_FROM_REFERENCES.md` | The reference-driven redesign brief. |
| `HANDOFF_TO_CODING_AGENT.md` | Handover note between agents. |
| `archive/AGENTS-2-old-english-entry-point.md` | An older English `AGENTS.md`, superseded by the current one. |

Moved here in round 40 (audit P2): the root of a repository is a table of contents, not a filing
cabinet.
